# dv-simpsons2

To run this application, you need to have Python installed on your system. *(Note: You may need to use `python` or `python3` depending on your Operating System).*

### Setup and Execution

**1. Install dependencies:**

```bash
pip install -r requirements.txt

```

*(If the command above doesn't work, try `pip3 install -r requirements.txt` or `python -m pip install -r requirements.txt`).*

**2. Navigate to the source folder and launch the app:**

```bash
cd ./src 
streamlit run dashboard.py

```
